# cqlib-tianyan — C Tutorial

A complete guide to using the **cqlib-tianyan** C binding to authenticate with, submit quantum circuits to, and retrieve calibrated results from the **Tianyan Quantum Cloud Platform** (`qc.zdxlz.com`).

The C binding wraps the Rust core via `extern "C"` functions. It is suitable for embedding in C or C++ projects, or for bridging to other languages that can call C shared libraries.

## 1. Building the Library

### 1.1 Build the Rust library

From the workspace root, run:

```sh
cargo build -p binding-c --release
```

This produces:

| Platform | Static library | Dynamic library |
|----------|---------------|-----------------|
| macOS    | `target/release/libbinding_c.a` | `target/release/libbinding_c.dylib` |
| Linux    | `target/release/libbinding_c.a` | `target/release/libbinding_c.so` |

The C header is auto-generated by [cbindgen](https://github.com/mozilla/cbindgen) and located at:

```
crates/binding-c/include/cqlib_tianyan.h
```

### 1.2 Compile your C program

Pass `-I` to point to the header directory, then link the static library with the platform-specific system libraries.

**macOS (static link):**

```sh
cc -Iinclude main.c \
   ../../target/release/libbinding_c.a \
   -framework Security \
   -framework CoreFoundation \
   -framework SystemConfiguration \
   -lc++ \
   -o main
```

**Linux (static link):**

```sh
cc -Iinclude main.c \
   ../../target/release/libbinding_c.a \
   -lpthread -ldl -lm \
   -o main
```

> **Tip**: When linking dynamically, replace the `.a` path with `-L../../target/release -lbinding_c` and ensure the library directory is on `LD_LIBRARY_PATH` (Linux) or `DYLD_LIBRARY_PATH` (macOS) at runtime.

### 1.3 Minimal `main.c` skeleton

```c
#include <stdio.h>
#include <stdlib.h>
#include "cqlib_tianyan.h"

int main(void) {
    const char *api_key = getenv("TIANYAN_API_KEY");
    if (!api_key) {
        fprintf(stderr, "Set TIANYAN_API_KEY\n");
        return 1;
    }

    TianyanPlatformC *platform = tianyan_platform_login(api_key);
    if (!platform) {
        char *err = tianyan_last_error();
        fprintf(stderr, "Login failed: %s\n", err ? err : "(unknown)");
        tianyan_string_free(err);
        return 1;
    }

    printf("Login successful!\n");
    tianyan_platform_free(platform);
    return 0;
}
```

## 2. Authentication

### 2.1 First-time login

Call `tianyan_platform_login` with your API key (OpenID). By default, the resulting credentials are stored in `~/.cqlib/tianyan/credentials.json` (macOS/Linux) so they can be reused on subsequent runs.

```c
TianyanPlatformC *platform = tianyan_platform_login(api_key);
if (!platform) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Login failed: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    return 1;
}
```

On success, the returned pointer owns a heap-allocated platform object. Always free it with `tianyan_platform_free()` when done.

### 2.2 Reuse saved credentials

On subsequent runs you can skip re-logging in. If the token is expired, the library automatically refreshes it:

```c
TianyanPlatformC *platform = tianyan_platform_from_credentials();
if (!platform) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Could not load credentials: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    return 1;
}
```

### 2.3 Custom authentication options

Use `TianyanConfigC` to customise saving, refresh, and path behaviour. All fields in the struct are optional; set a field to `NULL` (or `false`) to use the default.

```c
TianyanConfigC config = {
    .domain            = NULL,    // NULL → "qc.zdxlz.com"
    .credentials_path  = NULL,    // NULL → ~/.cqlib/tianyan/credentials.json
    .save_credentials  = false,   // do NOT write credentials to disk
    .auto_refresh      = false,   // do NOT re-login on token expiry
};

TianyanPlatformC *platform =
    tianyan_platform_login_with_config(api_key, &config);
```

| Field | Default | Description |
|-------|---------|-------------|
| `domain` | `"qc.zdxlz.com"` | Platform hostname |
| `credentials_path` | `~/.cqlib/tianyan/credentials.json` | Override the credentials file path |
| `save_credentials` | `true` | Persist token to disk after login/refresh |
| `auto_refresh` | `true` | Re-login automatically when token expires |

### 2.4 Load from a custom credentials path

```c
TianyanConfigC config = {
    .domain            = NULL,
    .credentials_path  = "/secure/vault/creds.json",
    .save_credentials  = true,
    .auto_refresh      = true,
};

TianyanPlatformC *platform =
    tianyan_platform_from_credentials_with_config(&config);
```

## 3. Listing & Inspecting Backends

### 3.1 List all backends

`tianyan_platform_list_backends` returns a NULL-terminated-length array. The caller receives ownership of each element; free the whole array with `tianyan_backend_list_free`.

```c
size_t n = 0;
TianyanBackendC **backends = tianyan_platform_list_backends(platform, &n);
if (!backends) {
    char *err = tianyan_last_error();
    fprintf(stderr, "list_backends failed: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    return 1;
}

for (size_t i = 0; i < n; i++) {
    const char *name         = tianyan_backend_name(backends[i]);
    const char *display_name = tianyan_backend_display_name(backends[i]);
    int status               = tianyan_backend_status(backends[i]);
    bool available           = tianyan_backend_is_available(backends[i]);

    printf("%-30s %-30s status=%d  available=%s\n",
           name, display_name, status, available ? "yes" : "no");
}

tianyan_backend_list_free(backends, n);
```

**Device types** returned by `tianyan_backend_device_type(backend)`:

| Code | Device type | Devices |
|---|---|---|
| `3` | Simulator | `tianyan_sw`, `tianyan_s`, `tianyan_tn`, `tianyan_tnn`, `tianyan_sa`, `tianyan_swn` |
| `1` | Photonic | `tianyan-p2000` |
| `0` | Superconducting | `tianyan176`, `tianyan176-2`, `tianyan24`, `tianyan504`, `tianyan-287`, `tianyan-294` |

Passing a `NULL` backend returns `-1`.

**Status codes** returned by `tianyan_backend_status`:

| Code | Meaning |
|------|---------|
| `0` | Running |
| `1` | Calibrating |
| `2` | Maintenance |
| `3` | Offline |
| `4` | Upgrading |
| `-1` | Unknown |

**Toll codes** returned by `tianyan_backend_toll`:

| Code | Meaning |
|------|---------|
| `1` | Free |
| `2` | Paid |
| `-1` | Unknown |

Only `Superconducting` devices support configuration downloads and readout calibration; qubit-count queries that depend on configuration have the same restriction.

Only `Superconducting` and `Simulator` devices can submit tasks; `Photonic` and `IonTrap` submissions fail locally.

`Auto` skips configuration download and calibration for non-superconducting devices and returns raw counts. Explicitly selecting `Enabled` on a non-superconducting device fails before submission. `Disabled` always returns raw counts. `is_available` reports running status only; it does not guarantee submission support.

### 3.2 Select a specific backend

```c
TianyanBackendC *backend = tianyan_platform_get_backend(platform, "tianyan-287");
if (!backend) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Backend not found: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    return 1;
}

printf("Selected : %s\n", tianyan_backend_name(backend));
printf("Status   : %d\n", tianyan_backend_status(backend));
printf("Toll     : %d\n", tianyan_backend_toll(backend));
printf("Available: %s\n", tianyan_backend_is_available(backend) ? "yes" : "no");

size_t num_qubits = 0;
if (tianyan_backend_num_qubits(backend, &num_qubits)) {
    printf("Physical qubits: %zu\n", num_qubits);
} else {
    char *err = tianyan_last_error();
    fprintf(stderr, "Could not load qubit count: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
}
```

> **Lifetimes**: `tianyan_backend_name()` and `tianyan_backend_display_name()` return `const char *` pointers whose lifetime is tied to the `TianyanBackendC` object. Do **not** free these strings; do **not** use them after the backend is freed.

`tianyan_backend_num_qubits()` supports only superconducting devices; other types return failure and set an error. It may download and parse the backend configuration on first use. It reports the physical qubit count, including disabled qubits.

## 4. Submitting Circuits

Circuits are expressed as **QCIS strings**. Gates and measurements are separated by `\n`.

### 4.1 Bell state example

The Bell state |Φ⁺⟩ = (|00⟩ + |11⟩) / √2 requires a Hadamard and a controlled-NOT. On `tianyan-287`, qubits Q1 and Q8 are directly coupled; the CZ gate is the native two-qubit gate, so CNOT is decomposed as `H(Q8) · CZ(Q1,Q8) · H(Q8)`.

```c
const char *circuits[] = {
    "H Q1\nH Q8\nCZ Q1 Q8\nH Q8\nM Q1\nM Q8",
};
size_t n_circuits = 1;
size_t shots      = 1000;

TianyanTaskC *task = tianyan_backend_run(backend, circuits, n_circuits, shots);
if (!task) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Submit failed: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    tianyan_backend_free(backend);
    tianyan_platform_free(platform);
    return 1;
}
```

`tianyan_backend_run` returns a task handle immediately. The circuit is queued on the cloud; results are retrieved later via polling.

### 4.2 Print the assigned task IDs

```c
size_t id_len = 0;
char **ids = tianyan_task_ids(task, &id_len);
if (ids) {
    for (size_t i = 0; i < id_len; i++) {
        printf("Task ID[%zu]: %s\n", i, ids[i]);
    }
    tianyan_task_ids_free(ids, id_len);
}
```

### 4.3 Submit via platform shortcut

You can also submit directly through the platform object without fetching a backend first:

```c
TianyanTaskC *task = tianyan_platform_submit(
    platform,
    circuits,
    n_circuits,
    shots,
    "tianyan-287"   /* device name */
);
```

## 5. Retrieving Results

### 5.1 Blocking wait

`tianyan_task_wait` polls until all circuits complete or the timeout expires. It returns a `TianyanResultList *`; free it with `tianyan_result_list_free()`.

```c
double timeout_secs       = 120.0;
double poll_interval_secs =   5.0;

TianyanResultList *results =
    tianyan_task_wait(task, timeout_secs, poll_interval_secs);
if (!results) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Wait failed: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    tianyan_task_free(task);
    return 1;
}
```

**Default behaviour**: `tianyan_task_wait` applies readout error calibration automatically on superconducting devices when calibration data is available and the circuit measures ≤ 14 qubits. To always get raw (uncalibrated) counts:

```c
TianyanResultList *raw_results =
    tianyan_task_wait_raw(task, timeout_secs, poll_interval_secs);
```

### 5.2 Iterate over results

```c
size_t len = tianyan_result_list_len(results);

for (size_t i = 0; i < len; i++) {
    const char *task_id  = tianyan_result_task_id(results, i);   // do NOT free
    size_t      shots_i  = tianyan_result_shots(results, i);
    size_t      n_qubits = tianyan_result_num_qubits(results, i);

    /* counts_json is a heap string — caller must free it */
    char *counts_json = tianyan_result_counts_json(results, i);

    printf("Task ID  : %s\n", task_id);
    printf("Shots    : %zu\n", shots_i);
    printf("Qubits   : %zu\n", n_qubits);
    printf("Counts   : %s\n", counts_json ? counts_json : "null");

    tianyan_string_free(counts_json);
}

tianyan_result_list_free(results);
```

> **`tianyan_result_task_id`** returns a `const char *` tied to the `TianyanResultList`. Do not free it; do not use it after `tianyan_result_list_free`.
> **`tianyan_result_counts_json`** returns a heap-allocated JSON string — always free it with `tianyan_string_free`.

### 5.3 Non-blocking status snapshot

```c
TianyanResultList *partial = tianyan_task_status_snapshot(task);
if (partial) {
    size_t done  = tianyan_result_list_len(partial);
    size_t total = tianyan_task_num_circuits(task);
    printf("%zu / %zu circuits complete\n", done, total);
    tianyan_result_list_free(partial);
}
```

## 6. Batch Submission

The Tianyan platform accepts up to **50 circuits per submission request**. `cqlib-tianyan` handles splitting automatically — you simply pass all circuits in one call.

```c
#define N_CIRCUITS 120

const char *circuits[N_CIRCUITS];
for (int i = 0; i < N_CIRCUITS; i++) {
    circuits[i] = "H Q0\nM Q0";
}

/* Automatically split into batches of 50, 50, 20 */
TianyanTaskC *task =
    tianyan_backend_run(backend, circuits, N_CIRCUITS, 1000);
if (!task) {
    char *err = tianyan_last_error();
    fprintf(stderr, "Batch submit failed: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
    return 1;
}

size_t id_len = 0;
char **ids = tianyan_task_ids(task, &id_len);
printf("Got %zu task IDs (expected %d)\n", id_len, N_CIRCUITS);
tianyan_task_ids_free(ids, id_len);
```

Results from `tianyan_task_wait` are returned in the same order as the submitted circuits.

## 7. Advanced: CalibrationMode

`tianyan_backend_run_with_mode` accepts an integer `mode` argument controlling readout error mitigation:

| Value | Name | Behaviour |
|-------|------|-----------|
| `0` | Auto *(default)* | On superconducting devices, apply calibration when data is available **and** the circuit measures ≤ 14 qubits; silently fall back to raw counts otherwise |
| `1` | Enabled | Require a superconducting device and calibration data, regardless of qubit count; reject other types before submission (caller is responsible for sufficient RAM) |
| `2` | Disabled | Always return raw counts; no mitigation applied |

> **The 14-qubit threshold for Auto**: the inverse confusion matrix requires O(4ⁿ) memory where n is the number of measured qubits. At n = 14 that is ~2 GiB; at n = 15 it is ~8 GiB. Above this threshold `Auto` silently falls back to raw counts to prevent out-of-memory crashes.

```c
/* Force calibration — fail if calibration data is missing */
TianyanTaskC *task_cal =
    tianyan_backend_run_with_mode(backend, circuits, n_circuits, shots, 1);

/* Always raw — no mitigation */
TianyanTaskC *task_raw =
    tianyan_backend_run_with_mode(backend, circuits, n_circuits, shots, 2);

/* Convenience alias for mode=2 */
TianyanTaskC *task_raw2 =
    tianyan_backend_run_raw(backend, circuits, n_circuits, shots);
```

Retrieve results the same way regardless of mode — the calibration decision is baked into the task at submission time:

```c
TianyanResultList *cal_results =
    tianyan_task_wait(task_cal, 120.0, 5.0);
TianyanResultList *raw_results =
    tianyan_task_wait(task_raw, 120.0, 5.0);
```

## 8. Error Handling

The C binding uses a **thread-local error slot**. When any function fails it:

1. Stores a descriptive error string in thread-local storage.
2. Returns `NULL` (for pointer-returning functions) or a sentinel value.

### 8.1 The error pattern

Always check the return value, then call `tianyan_last_error()` on failure:

```c
TianyanPlatformC *platform = tianyan_platform_login(api_key);
if (!platform) {
    char *err = tianyan_last_error();   /* heap-allocated — caller frees */
    fprintf(stderr, "Error: %s\n", err ? err : "(no error message)");
    tianyan_string_free(err);           /* always free, even if NULL-safe */
    return 1;
}
```

### 8.2 `tianyan_error_clear`

Call `tianyan_error_clear()` to reset the error slot before a block of calls whose individual failures you want to distinguish:

```c
tianyan_error_clear();

TianyanBackendC *backend = tianyan_platform_get_backend(platform, name);
if (!backend) {
    char *err = tianyan_last_error();
    /* err now reflects exactly this get_backend failure */
    fprintf(stderr, "get_backend: %s\n", err ? err : "(unknown)");
    tianyan_string_free(err);
}
```

### 8.3 Check every call

Every pointer-returning function can return `NULL` on failure. A defensive wrapper pattern:

```c
#define CHECK(ptr, label) \
    do { \
        if (!(ptr)) { \
            char *_e = tianyan_last_error(); \
            fprintf(stderr, "[%s] %s\n", label, _e ? _e : "(unknown)"); \
            tianyan_string_free(_e); \
            goto cleanup; \
        } \
    } while (0)

TianyanPlatformC *platform = tianyan_platform_login(api_key);
CHECK(platform, "login");

TianyanBackendC *backend = tianyan_platform_get_backend(platform, "tianyan-287");
CHECK(backend, "get_backend");

TianyanTaskC *task = tianyan_backend_run(backend, circuits, n_circuits, shots);
CHECK(task, "run");

TianyanResultList *results = tianyan_task_wait(task, 120.0, 5.0);
CHECK(results, "wait");

/* ... process results ... */

cleanup:
    tianyan_result_list_free(results);
    tianyan_task_free(task);
    tianyan_backend_free(backend);
    tianyan_platform_free(platform);
```

## 9. Memory Management

The C API follows a consistent set of ownership rules. Understanding them prevents both leaks and double-frees.

### 9.1 `const char *` — do NOT free

Functions that return `const char *` give you a **borrowed pointer** whose lifetime is tied to the parent object. The parent retains ownership.

```c
/* Lifetime tied to backend — do NOT free */
const char *name = tianyan_backend_name(backend);
const char *disp = tianyan_backend_display_name(backend);

/* Lifetime tied to result list — do NOT free */
const char *task_id = tianyan_result_task_id(results, 0);
```

These pointers become invalid when the parent object is freed.

### 9.2 `char *` — caller must free with `tianyan_string_free`

Functions that return `char *` (mutable) **transfer ownership** to the caller. Always free with `tianyan_string_free`, never with the system `free()`.

```c
char *err   = tianyan_last_error();       /* free after use */
char *json  = tianyan_result_counts_json(results, i); /* free after use */

tianyan_string_free(err);
tianyan_string_free(json);
```

`tianyan_string_free(NULL)` is safe — it is a no-op.

### 9.3 `char **` from `tianyan_task_ids` — free with `tianyan_task_ids_free`

```c
size_t id_len = 0;
char **ids = tianyan_task_ids(task, &id_len);
/* ... use ids[0] .. ids[id_len-1] ... */
tianyan_task_ids_free(ids, id_len);
```

### 9.4 `TianyanBackendC **` from `tianyan_platform_list_backends` — free with `tianyan_backend_list_free`

```c
size_t n = 0;
TianyanBackendC **backends = tianyan_platform_list_backends(platform, &n);
/* ... use backends[0] .. backends[n-1] ... */
tianyan_backend_list_free(backends, n);
```

### 9.5 All `_free()` functions are NULL-safe

You may pass `NULL` to any `_free()` function without crashing:

```c
tianyan_platform_free(NULL);   /* safe */
tianyan_backend_free(NULL);    /* safe */
tianyan_task_free(NULL);       /* safe */
tianyan_result_list_free(NULL); /* safe */
tianyan_string_free(NULL);     /* safe */
```

### 9.6 Ownership summary

| Function | Return type | Owned by | Free with |
|----------|------------|----------|-----------|
| `tianyan_platform_login` | `TianyanPlatformC *` | Caller | `tianyan_platform_free` |
| `tianyan_platform_get_backend` | `TianyanBackendC *` | Caller | `tianyan_backend_free` |
| `tianyan_platform_list_backends` | `TianyanBackendC **` | Caller | `tianyan_backend_list_free` |
| `tianyan_backend_run` / `_raw` / `_with_mode` | `TianyanTaskC *` | Caller | `tianyan_task_free` |
| `tianyan_platform_submit` | `TianyanTaskC *` | Caller | `tianyan_task_free` |
| `tianyan_task_wait` / `_raw` / `_status_snapshot` | `TianyanResultList *` | Caller | `tianyan_result_list_free` |
| `tianyan_task_ids` | `char **` | Caller | `tianyan_task_ids_free` |
| `tianyan_last_error` | `char *` | Caller | `tianyan_string_free` |
| `tianyan_result_counts_json` | `char *` | Caller | `tianyan_string_free` |
| `tianyan_backend_name` | `const char *` | Backend | — (do not free) |
| `tianyan_backend_display_name` | `const char *` | Backend | — (do not free) |
| `tianyan_result_task_id` | `const char *` | ResultList | — (do not free) |

## Complete Example

A self-contained C program that logs in, selects a backend, submits a Bell-state circuit, and prints the result counts.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "cqlib_tianyan.h"

/* Print and free the last error message. */
static void print_last_error(const char *context) {
    char *err = tianyan_last_error();
    fprintf(stderr, "[%s] %s\n", context, err ? err : "(unknown error)");
    tianyan_string_free(err);
}

int main(void) {
    int exit_code = 1;

    /* ------------------------------------------------------------------ */
    /* 1. Authenticate                                                      */
    /* ------------------------------------------------------------------ */
    const char *api_key = getenv("TIANYAN_API_KEY");
    if (!api_key || strlen(api_key) == 0) {
        fprintf(stderr, "Error: set TIANYAN_API_KEY environment variable.\n");
        return 1;
    }

    TianyanPlatformC *platform = tianyan_platform_login(api_key);
    if (!platform) {
        print_last_error("login");
        return 1;
    }
    printf("Logged in successfully.\n");

    /* ------------------------------------------------------------------ */
    /* 2. Select backend                                                    */
    /* ------------------------------------------------------------------ */
    TianyanBackendC *backend =
        tianyan_platform_get_backend(platform, "tianyan-287");
    if (!backend) {
        print_last_error("get_backend");
        goto free_platform;
    }

    printf("Backend  : %s\n", tianyan_backend_name(backend));
    printf("Display  : %s\n", tianyan_backend_display_name(backend));
    printf("Status   : %d\n", tianyan_backend_status(backend));
    printf("Toll     : %d\n", tianyan_backend_toll(backend));
    printf("Available: %s\n",
           tianyan_backend_is_available(backend) ? "yes" : "no");

    /* ------------------------------------------------------------------ */
    /* 3. Submit Bell-state circuit                                         */
    /*    Q1 ↔ Q8 are coupled on tianyan-287.                              */
    /*    CNOT = H(Q8) · CZ(Q1,Q8) · H(Q8)                                */
    /* ------------------------------------------------------------------ */
    const char *circuits[] = {
        "H Q1\nH Q8\nCZ Q1 Q8\nH Q8\nM Q1\nM Q8",
    };
    const size_t n_circuits = 1;
    const size_t shots      = 1000;

    TianyanTaskC *task =
        tianyan_backend_run(backend, circuits, n_circuits, shots);
    if (!task) {
        print_last_error("backend_run");
        goto free_backend;
    }

    /* Print assigned task IDs */
    size_t id_len = 0;
    char **ids = tianyan_task_ids(task, &id_len);
    if (ids) {
        for (size_t i = 0; i < id_len; i++) {
            printf("Task ID[%zu]: %s\n", i, ids[i]);
        }
        tianyan_task_ids_free(ids, id_len);
    }

    /* ------------------------------------------------------------------ */
    /* 4. Wait for results (calibrated, default CalibrationMode Auto)      */
    /* ------------------------------------------------------------------ */
    printf("Waiting for results (up to 120 s)...\n");
    TianyanResultList *results = tianyan_task_wait(task, 120.0, 5.0);
    if (!results) {
        print_last_error("task_wait");
        goto free_task;
    }

    /* ------------------------------------------------------------------ */
    /* 5. Print results                                                     */
    /* ------------------------------------------------------------------ */
    size_t n_results = tianyan_result_list_len(results);
    printf("Received %zu result(s).\n", n_results);

    for (size_t i = 0; i < n_results; i++) {
        const char *task_id  = tianyan_result_task_id(results, i); /* no free */
        size_t      shots_i  = tianyan_result_shots(results, i);
        size_t      n_qubits = tianyan_result_num_qubits(results, i);
        char       *json     = tianyan_result_counts_json(results, i); /* free! */

        printf("\n--- Result %zu ---\n", i);
        printf("Task ID : %s\n", task_id ? task_id : "(null)");
        printf("Shots   : %zu\n", shots_i);
        printf("Qubits  : %zu\n", n_qubits);
        printf("Counts  : %s\n", json ? json : "null");

        tianyan_string_free(json);
    }

    exit_code = 0;

    /* ------------------------------------------------------------------ */
    /* 6. Cleanup                                                           */
    /* ------------------------------------------------------------------ */
    tianyan_result_list_free(results);
free_task:
    tianyan_task_free(task);
free_backend:
    tianyan_backend_free(backend);
free_platform:
    tianyan_platform_free(platform);

    return exit_code;
}
```
